Name of Quantlet: TSA_ch5b_dcc_estimation

Published in: Time Series Analysis and Forecasting

Description: Estimates a DCC-GARCH(1,1) model for S&P 500 and DAX daily returns using two-step estimation. Step 1 fits univariate GARCH(1,1) with Student-t innovations. Step 2 estimates DCC parameters (a, b) via composite likelihood. Compares DCC dynamic correlations against 126-day rolling correlations, showing that DCC is smoother, reacts faster to shocks, and avoids the ghost feature problem of rolling windows.

Keywords: DCC, dynamic conditional correlation, GARCH, two-step estimation, composite likelihood, rolling correlation, S&P 500, DAX

Author: Daniel Traian Pele

Datafile: yfinance API (^GSPC, ^GDAXI), 2004-2024

Output: ch5b_dcc_vs_rolling.pdf

Example: DCC captures the correlation spike during GFC (2008) within days, while 126-day rolling correlation lags by several weeks. Estimated parameters: a = 0.04, b = 0.94, indicating highly persistent correlations.
